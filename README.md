## Task 1 – Nmap

For Task 1, I performed a basic Nmap TCP port scan on an authorized host and saved the scan output as a text file.

The scan identified the following open TCP ports:

- 135/tcp – msrpc
- 139/tcp – netbios-ssn
- 445/tcp – microsoft-ds
- 1521/tcp – oracle
- 5500/tcp – hotline

The repository includes the scan output, report and screenshot evidence.
